# 🚗 Precios Autos Argentina

![Angular](https://img.shields.io/badge/Angular-21-DD0031?style=for-the-badge&logo=angular)
![TypeScript](https://img.shields.io/badge/TypeScript-5.x-3178C6?style=for-the-badge&logo=typescript)
![License](https://img.shields.io/badge/License-MIT-green?style=for-the-badge)

Una herramienta moderna y eficiente para consultar precios de vehículos en el mercado argentino. Esta aplicación consume APIs en tiempo real para ofrecer valores actualizados tanto en **Pesos Argentinos (ARS)** como en **Dólares (USD)**, facilitando la comparación en un contexto económico volátil.

## ✨ Características

- 📊 **Cotización Multimoneda:** Visualización de precios en ARS y USD.
- 🔄 **Datos en Tiempo Real:** Consumo de API para asegurar información vigente.
- ⚡ **Performance:** Construido sobre Angular 21 para una experiencia de usuario fluida (SPA).
- 📱 **Diseño Responsive:** Optimizado para consultas desde móviles o escritorio.

## 🛠️ Stack Tecnológico

- **Frontend:** [Angular 21](https://angular.dev/)
- **Lenguaje:** TypeScript
- **Estilos:** CSS / SCSS
- **Testing:** Vitest

## 🚀 Instalación y Uso

Para correr este proyecto localmente, sigue estos pasos:

1. **Clonar el repositorio:**
   ```bash
   git clone [https://github.com/EmanuelBertorello/PreciosAutosArgentina.git](https://github.com/EmanuelBertorello/PreciosAutosArgentina.git)
   cd PreciosAutosArgentina
Instalar dependencias:

Bash
npm install
Iniciar el servidor de desarrollo:

Bash
ng serve
Luego, navega a http://localhost:4200/.

🧪 Testing
Para ejecutar los tests unitarios con Vitest:

Bash
ng test
